# Kyaw Soe Win — IT Portfolio

A responsive bilingual (English/Myanmar) static portfolio built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `kyaw-soe-win-portfolio`.
2. Upload the contents of this folder (upload `index.html`, `css`, `js`, and `assets`; do not upload only the ZIP file).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait a few minutes; GitHub will show the published website URL in Settings → Pages.
